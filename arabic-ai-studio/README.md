# مِداد — مساحة الذكاء الاصطناعي العربية

نموذج أولي مستقل عن تطبيق «محلل يحيى»، في هذا المجلد وحده. لا يستورد شيفرة المحلل أو قاعدة بياناته ولا يشارك حساباته. التطبيق محليّ التشغيل؛ لم يُبنَ بعد كخدمة مستضافة أو منتج تجاري.

## التشغيل

1. ثبّت Node.js 22+ و[Ollama](https://ollama.com/) على جهازك.
2. نزّل نموذجاً محلياً ملائماً لمواصفات جهازك، مثلاً `ollama pull qwen2.5:7b`. حجم النموذج واستهلاك الذاكرة يختلفان بحسب النسخة.
3. شغّل Ollama ثم من هذا المجلد نفّذ:

   ```sh
   npm start
   ```

4. افتح `http://127.0.0.1:4173`. يمكن تغيير المنفذ أو اسم النموذج عبر `PORT` و`OLLAMA_MODEL`.

## ما يفعله النموذج الأولي

- مساحة عمل عربية: يطلب من النموذج المحلي اقتراح خطة، ثم يتيح للمستخدم مراجعتها قبل إنشاء مسودة نصية وتنزيلها بصيغة Markdown. تتضمن قوالب أولية لأعمال صغيرة وسجل مهام محفوظاً محلياً في المتصفح وقابلاً للمسح.
- يسمح بإضافة ملف TXT أو MD حتى 16 كيلوبايت؛ يُقرأ في المتصفح ويُرسل نصه إلى Ollama المحلي، ولا تُخزّن الملفات.
- يفحص اتصال Ollama وتوفر النموذج المحدد، ويعرض أمر تنزيله إذا كان غير موجود.
- دليل استكشافي مصنّف بأدوات ذكاء اصطناعي وروابط مواقعها الرسمية، مع بحث وتصنيف.
- لا يرسل التطبيق المحادثات إلى واجهة خارجية، ولا ينفذ أوامر النظام أو يزور مواقع أو يتخذ إجراءات بالنيابة عن المستخدم.
- سجل المهام يحفظ وصف المهمة والمخرجات في `localStorage` على المتصفح المستخدم. لا تحفظ ملفات المراجع فيه؛ استخدم زر مسح السجل أو امسح بيانات الموقع عند الحاجة، ولا تستخدمه على جهاز مشترك لبيانات حساسة.

## الحدود والتكاليف

هذا ليس بديلاً مكافئاً لـ Manus حالياً: لا يتضمن بحث ويب حيّاً أو استخراجاً من PDF/Office أو استدعاء أدوات أو حسابات سحابية أو مزامنة. المخرجات نص مولّد محلياً وتحتاج تحققاً بشرياً. جودة العربية والسرعة تعتمدان على النموذج والجهاز.

لا توجد رسوم اشتراك لمزود نموذج في هذا الإعداد المحلي، لكن ذلك لا يعني انعدام التكلفة: الجهاز والكهرباء والإنترنت والصيانة لها تكاليف، كما أن استضافة منتج لعملاء تحتاج بنية وتشغيلاً. الدليل بداية منتقاة وليس قائمة شاملة؛ أدوات الذكاء الاصطناعي وأسعارها تتغير باستمرار.

لم يُفعّل تحصيل المدفوعات. قبل عرض باقات في السعودية، اختبر الحاجة والاستعداد للدفع، واحسب تكلفة الوحدة، ثم تحقّق من مزود مرخص يدعم وسائل الدفع المطلوبة ومتطلبات الفوترة والضرائب والخصوصية قبل أي تكامل.
