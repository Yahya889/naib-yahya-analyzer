# نائب | منصة إدارة الأعمال

واجهة عربية متجاوبة لإدارة العقود، والحركات المالية، والملفات. تعمل باستخدام Node.js المدمج دون اعتماديات خارجية.

## التشغيل

يتطلب Node.js 18 أو أحدث:

```bash
npm start
```

افتح <http://127.0.0.1:3000>. لتغيير المنفذ استخدم `PORT=8080 npm start`. تُنشأ نسخ احتياطية محلية تلقائية لقاعدة البيانات (آخر خمس نسخ) في `data/backups/`؛ احتفظ أيضًا بنسخة احتياطية خارج الجهاز.

لتشفير قاعدة البيانات والملفات المرفوعة أثناء التخزين، عيّن مفتاحًا سريًا من 32 بايت قبل التشغيل:

```bash
NAIB_ENCRYPTION_KEY="$(openssl rand -hex 32)" npm start
```

احفظ المفتاح في مدير أسرار آمن ولا تفقده؛ لا يمكن قراءة البيانات المشفرة أو النسخ الاحتياطية المشفرة من دونه. عند تفعيل التشفير تُشفّر قاعدة البيانات القديمة عند أول قراءة، ويُشفّر كل ملف قديم عند أول فتح له. يقتصر الخادم افتراضيًا على الاتصالات المحلية؛ لا تعرضه على الإنترنت دون إضافة مصادقة وحماية مناسبة.

## المزايا والحدود

- مراجعة أولية لنصوص العقود بقائمة عامة من ستة بنود، مع نسبة اكتمال محسوبة من البنود الموجودة. النسبة ليست نسبة توافق قانوني، ولا تتحقق من الامتثال للأنظمة السعودية؛ يجب مراجعة العقد مع محامٍ مرخص.
- تسجيل الإيرادات والمصروفات مع تصفية بالبحث والنوع والفترة والتاريخ، ومخطط ملخص، وإمكانية تصدير CSV متوافق مع Excel وطباعة التقرير أو حفظه PDF من المتصفح. الملخصات مبنية على الحركات المسجلة فقط ولا تحل محل برنامج محاسبي معتمد أو متطلبات الفوترة والضرائب.
- رفع PDF وPNG وJPG وWEBP وTXT حتى 25 ميغابايت للملف، مع معاينة محلية قبل الرفع والتحقق من امتداد الملف ونوعه وتوقيعه وتصنيفه في فئة. التخزين محلي على الجهاز.
- سجل محلي لعمليات الإضافة والرفع والحذف، ونسخ احتياطية دورية لقاعدة البيانات.
- تشفير اختياري للبيانات المخزنة باستخدام AES-256-GCM عند تعيين `NAIB_ENCRYPTION_KEY`.

## API

- `GET /api/summary` — إحصائيات مساحة العمل.
- `GET /api/audit-log` — آخر 100 عملية مسجلة.
- `GET, POST /api/contracts` — قائمة العقود وإضافة عقد مع نتيجة الفحص الأولي.
- `GET, POST /api/invoices` — قائمة الحركات المالية وإضافة إيراد أو مصروف.
- `GET, POST /api/files` — قائمة الملفات ورفع ملف بصيغة `multipart/form-data` تحت اسم الحقل `file`، مع حقل اختياري `category` (عقود، فواتير، هوية، عام).
- `GET, DELETE /api/files/:id` — تنزيل/معاينة ملف أو حذفه.
