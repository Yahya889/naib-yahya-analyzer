# نائب | منصة إدارة الأعمال

واجهة عربية متجاوبة لإدارة العقود، والحركات المالية، والملفات. تعمل باستخدام Node.js المدمج دون اعتماديات خارجية.

## التشغيل

يتطلب Node.js 18 أو أحدث:

```bash
npm start
```

افتح <http://127.0.0.1:3000>. لتغيير المنفذ استخدم `PORT=8080 npm start`. يُحفظ المحتوى في `data/database.json` والملفات المرفوعة في `data/uploads/`؛ خذ نسخة احتياطية من المجلد `data` بانتظام. يقتصر الخادم افتراضيًا على الاتصالات المحلية؛ لا تعرضه على الإنترنت دون إضافة مصادقة وحماية مناسبة.

## المزايا والحدود

- مراجعة أولية لنصوص العقود بقائمة عامة من البنود المقترح التحقق منها. هذا الفحص ليس استشارة قانونية ولا يتحقق من امتثال العقد للأنظمة السعودية؛ يجب مراجعته من محامٍ مرخص.
- تسجيل الإيرادات والمصروفات وعرض ملخص للحركات المسجلة. لا يحل النظام محل برنامج محاسبي معتمد أو متطلبات الفوترة والضرائب.
- رفع PDF وPNG وJPG وWEBP وTXT حتى 5 ميغابايت للملف، مع التحقق من امتداد الملف ونوعه وتوقيعه. التخزين محلي على الجهاز.
- طباعة تقارير العقود أو حفظها بصيغة PDF من نافذة الطباعة في المتصفح.

## API

- `GET /api/summary` — إحصائيات مساحة العمل.
- `GET, POST /api/contracts` — قائمة العقود وإضافة عقد مع نتيجة الفحص الأولي.
- `GET, POST /api/invoices` — قائمة الحركات المالية وإضافة إيراد أو مصروف.
- `GET, POST /api/files` — قائمة الملفات ورفع ملف بصيغة `multipart/form-data` تحت اسم الحقل `file`.
- `GET, DELETE /api/files/:id` — تنزيل/معاينة ملف أو حذفه.
